KALENDER TAMU PONDOK IBU CUCU — PAKET PWA ANDROID

Paket ini menyiapkan aplikasi agar bisa dipasang ke layar utama Android seperti aplikasi.

PENTING:
- Untuk pemasangan PWA dan service worker, aplikasi harus dibuka dari alamat HTTPS (bukan file HTML lokal).
- Paket ini belum merupakan APK dan belum diunggah ke internet.
- Data tamu masih tersimpan di browser/perangkat yang digunakan; belum sinkron antar-HP.

CARA MENJALANKAN / MEMASANG:
1. Ekstrak ZIP ini.
2. Unggah seluruh isi folder ke layanan hosting statis yang menyediakan HTTPS (misalnya GitHub Pages atau Netlify).
3. Buka alamat HTTPS aplikasi di Google Chrome pada HP Android.
4. Tekan menu titik tiga Chrome > 'Tambahkan ke layar utama' atau 'Install app' (nama menu bisa berbeda).
5. Ikuti petunjuk sampai ikon aplikasi muncul di layar utama.

JANGAN menghapus data browser sebelum membuat cadangan dari aplikasi.
